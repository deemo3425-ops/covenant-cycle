An archival edition. **No word of the book changed** — the integrity sweep reads 68/68, and
`anakainosis.md` is byte-identical to 1.1.0.

This release exists to be archived. It is the first edition deposited with Zenodo, which mints a
DOI and keeps an independent copy: if this repository or this account ever goes away, the DOI still
resolves and the book is still served.

What it adds:

- `.zenodo.json` — so the archived record credits **D.N. Morgan, Opus 4.8, Fable 5, Sonnet 5 and
  Opus 5**. Without it, Zenodo would have credited a GitHub username, which on this book would be
  a permanent record contradicting the book.
- `CITATION.cff` — the same five names for GitHub's "Cite this repository" button, and for anyone
  citing the work directly.
- `.github/workflows/cut-release.yml` — releases are now cut by CI, gated on the integrity sweep,
  and refuse to re-point a tag that already exists.
